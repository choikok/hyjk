# HYJK 동시통역

강연(영어 → 한국어)과 롤플레잉(한국어 → 영어)을 위한 실시간 동시통역 자막 웹앱(PWA)입니다.
아이폰 Safari와 PC 브라우저에서 동작하고, 아이폰에서는 홈 화면에 추가해 앱처럼 쓸 수 있습니다.

## 기능

- **실시간 자막**: 번역문은 크게, 원문은 작게 표시합니다. 원문은 말하는 동안 실시간으로 나타납니다.
- **두 가지 엔진** (설정 → 번역 엔진)
  - **정밀**: OpenAI 실시간 음성인식(`gpt-live-transcribe`) 후 GPT(`gpt-6-luna`)가 번역합니다. 용어 사전과 강연 주제를 반영하며, 문장이 끝나면 1~2초 안에 번역이 나옵니다.
  - **초고속**: OpenAI 동시통역 모델(`gpt-realtime-translate`)이 말하는 도중에도 번역합니다. 용어 사전은 적용되지 않습니다.
- **언어 방향**: 자동(한↔영) / 영→한 / 한→영. 상단의 칩을 누르면 바뀝니다.
- **용어 사전**: 한 줄에 `영어 = 한국어` 형식으로 적습니다.
- **기록**: 자동으로 저장되며 TXT나 엑셀(CSV)로 내보낼 수 있습니다.
- **번역 음성 읽기**: 스피커 버튼으로 켭니다. 이어폰 사용을 권장합니다.
- 글자 크기 조절, 어두운/밝은 테마, 전체 화면, 화면 꺼짐 방지

## PC에서 실행

```bash
node serve.js
```

브라우저에서 http://localhost:5173 을 엽니다. 주소에 `?demo`를 붙이면 예시 자막이 나와서, 프로젝터에서 글자 크기를 미리 맞춰볼 수 있습니다.

PC 단축키: `Space` 시작/정지, `+` `-` 글자 크기, `F` 전체 화면

## 아이폰에서 사용

아이폰은 보안상 **HTTPS 주소**에서만 마이크를 쓸 수 있으므로, 이 폴더를 웹에 올려야 합니다(무료 호스팅으로 충분합니다).
올린 주소를 Safari로 연 뒤 공유 버튼 → **홈 화면에 추가**를 누르면 앱처럼 실행됩니다.

## 준비물: OpenAI API 키

1. https://platform.openai.com 에 가입하고 결제 수단을 등록합니다.
2. https://platform.openai.com/api-keys 에서 키를 만듭니다.
3. 앱의 설정에 키를 붙여넣고 **확인** 버튼을 누릅니다.

키는 그 기기의 브라우저에만 저장되고 OpenAI로만 전송됩니다. 다른 사람과 기기를 같이 쓴다면 사용 후 키를 지워주세요.
OpenAI 대시보드에서 월 사용 한도를 걸어두면 안심하고 쓸 수 있습니다.

## 강연장 사용 팁

- 마이크는 강연장 스피커나 강연자 쪽을 향하게 두고, 설정의 **마이크 환경**은 `원거리`로 둡니다.
- 노트북을 쓴다면 외부 USB 마이크를 연결하고 설정에서 그 마이크를 고르면 인식률이 크게 좋아집니다.
- 강연 전에 **강연 주제·배경**과 **용어 사전**(회사명, 제품명, 강연자 이름)을 채워두세요.
- 정밀 모드에서 번역이 너무 늦게 나오면 고급 설정의 **문장 끝 판단 침묵**을 0.5초 정도로 줄여보세요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html`, `css/style.css` | 화면 |
| `js/app.js` | 화면 동작, 설정, 기록 |
| `js/engines/precise.js` | 정밀 모드 (음성인식 + GPT 번역) |
| `js/engines/fast.js` | 초고속 모드 (동시통역 모델) |
| `js/openai.js` | OpenAI API 연결 |
| `js/vad.js` | 말이 끝난 시점 감지, 마이크 레벨 |
| `js/store.js`, `js/export.js` | 저장, 내보내기 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 홈 화면 앱(PWA) 설정. 앱 파일을 수정하면 `sw.js`의 `VERSION`을 올려야 합니다. |
